Setup checklist
  1. Create a Discord application at discord.com/developers/applications
  2. Create a bot under the application → copy the Bot Token
  3. Enable Server Members Intent in the bot settings (Privileged Gateway Intents)
  4. Set OAuth2 redirect URL to {{ config.get('oauth_redirect_url', 'your-panel-url/discord/callback') }}
  5. Invite the bot to the main server and every promotion server with the bot scope and permission to view members; auto-join also needs permission to add members
  6. Add https://your-panel/discord/callback to the OAuth2 redirects in the Discord developer portal and paste the same URL into “OAuth2 Redirect URL”
  7. Fill in all fields above and click Save. User linking requests identify + guilds.join
  8. Configure promotion slots (1-5) with server IDs and valid https://discord.gg/... invite URLs
  9. Use Test connection, then Test on each promotion slot until it reports Connected
